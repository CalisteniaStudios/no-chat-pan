# No Chat Pan 1.0.0

Initial free, public MIT-licensed release for Foundry VTT 13 and 14.

- Completely disables core chat-bubble camera panning while active.
- Hides the core Pan to Token Speaker option.
- Keeps messages and bubbles working normally.
- Does not modify saved client preferences.
- System-agnostic, with no dependencies.

Install using `no-chat-pan-1.0.0.zip`, restart Foundry, and enable the
module in the desired world. All connected clients should reload once.
